# Мерей Нұрланқызы — жеке сайт-портфолио

## Жоба құрылымы
- `index.html` — басты бет
- `about.html` — мен туралы
- `skills.html` — дағдылар
- `portfolio.html` — жобалар мен жетістіктер
- `contact.html` — байланыс
- `style.css` — барлық беттердің дизайны
- `script.js` — мобильді мәзір, тақырып режимі, форма тексеруі
- `profile.jpg` — пайдаланушы ұсынған фотосурет
- `resume.pdf` — түйіндеме
- `avatar.mp4` — HeyGen видеосын осы жерге қосу керек

## Компьютерде іске қосу
1. MyPortfolio бумасын Visual Studio Code арқылы ашыңыз.
2. VS Code кеңейтімдерінен Live Server орнатыңыз.
3. `index.html` файлын ашып, оң жақ батырмамен `Open with Live Server` таңдаңыз.

## HeyGen видеосын қосу
HeyGen платформасынан MP4 видеоны жүктеп алып, `videos` бумасына `avatar.mp4` атауымен салыңыз. Видео автоматты түрде қосылмайды; оны көруші өзі Play батырмасымен іске қосады.

## GitHub және Vercel
1. GitHub-та жаңа репозиторий құрыңыз.
2. Осы буманың ішіндегі барлық файлдар мен бумаларды репозиторийге жүктеңіз.
3. Vercel-ге GitHub арқылы кіріп, `Add New → Project` таңдаңыз.
4. Репозиторийді Import етіңіз. Framework Preset: `Other`; Build Command бос.
5. Deploy басыңыз.

Ескерту: байланыс формасы демонстрациялық, серверге хабарлама жібермейді. Сайтқа жеке құпия деректерді қоспаңыз.
